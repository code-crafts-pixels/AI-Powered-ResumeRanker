# 🚀 Resume Rank AI

**Resume Rank AI** is an AI-powered web application that analyzes resumes and ranks candidates based on job descriptions and skill relevance. The platform helps recruiters and job seekers quickly evaluate resume quality and match it with role requirements.



## 📌 Features

- Upload and analyze resumes instantly  
- AI-based resume ranking system  
- Job description matching  
- Skill extraction & relevance scoring  
- User-friendly and responsive UI  
- Fast and secure processing  


## 🛠️ Tech Stack

- Frontend: React.js / Vite  
- Backend: Node.js, Express.js  
- AI/NLP: OpenAI / ML-based resume parsing  
- Styling: Tailwind CSS / CSS3  
- Hosting: Base44

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

### 1️⃣ Clone the Repository
```
git clone https://github.com/your-username/resume-rank-ai.git
cd resume-rank-ai
```

### 2️⃣ Install Dependencies

#### For frontend:
```
npm install
```
#### For backend:
```
cd backend
npm install
```
### 3️⃣ Environment Variables

Create a .env file in the backend folder:
```
PORT=5000
OPENAI_API_KEY=your_api_key_here
```

### 4️⃣ Run Backend Server
```
npm start
or
nodemon server.js
```

### 5️⃣ Run Frontend
```
npm run dev
```
**6️⃣ Open in Browser**
```
http://localhost:5173
```
